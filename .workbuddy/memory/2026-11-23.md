## 产出：完整实现（同日晚）

- **39 个 TS 脚本**：`app/`(Entry/FSM/RunContext)、`config/`(GameTuning/PieceShapeTable/ThemeConfig)、`core/`(9 个纯逻辑文件，禁 cc)、`controller/`、`view/`(Board/Piece/Hud/Banner/Float/Dialog/BlockView)、`ui/`(UIButton/UIFactory/LayoutAdapter)、`service/`(Asset/Audio/Storage/Haptic/Platform)、`fx/`、`utils/`。
- **场景**：`assets/scenes/Main.scene` 基于编辑器自带的 `scene-2d.scene` 模板改（Canvas+Camera+Widget+SceneGlobals）。
- **入口机制（重要经验）**：`.scene` 里写自定义组件 `"__type__": "GameEntry"` 会报 `Missing class`（编辑器/构建期按脚本 uuid 解析，不按 @ccclass 名）。改为 `Bootstrap.ts` 监听 `Director.EVENT_AFTER_SCENE_LAUNCH` 后 `canvas.addComponent(GameEntry)`，构建与运行均正常。
- **美术**：ImageGen 生成 1 张背景 + 5 个方块（提示 transparent 时模型会把棋盘格画成底纹），用 PIL 从边缘泛洪抠图、按 alpha>200 核心区归一尺寸到 160²、背景裁到 750×1334 并 JPEG 压到 43KB；右下角 AI 水印用裁切+拉伸去掉。音效 10 个用 Python 合成 WAV（共 136KB）。
- **踩坑**：Cocos 一个节点只能挂一个 UIRenderer —— 同节点先 add Graphics 再 add Sprite 会被拒绝（"Can't add renderable component"），导致背景全黑、方块兜底失效。修法：渲染器各挂独立子节点。
- **验证**：`tsc --noEmit` 0 错误；29 项 node 单测全绿；`CocosCreator.exe --build platform=web-mobile` 成功；puppeteer 驱动本机 Chrome 冒烟：加载 → playing，10 次直落 1275 分，21 次直落判负、结算弹窗正常，触摸无报错。截图存 `docs/screenshots/`。
- **环境**：本机 shell 带 `ELECTRON_RUN_AS_NODE=1`，直接调 CocosCreator.exe 会被当成 node 执行；构建需 `env -u ELECTRON_RUN_AS_NODE -u NODE_OPTIONS`。
